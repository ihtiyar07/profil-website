## 1. Bağlam
Büyük ölçekli analitik ve telemetri platformlarında kullanıcılar; 30 günlük yüksek frekanslı sensör geçmişini, borsa emir defterlerini veya makine telemetrisini yüksek çözünürlüklü grafikler üzerinde anlık olarak incelemek ister. 

Böyle bir sorgu veritabanından çekildiğinde **client**'a yüz binlerce veri satırının (timestamp, double değerler, durum flag'leri) transfer edilmesi gerekir. Bu proje; veritabanından client tarayıcısına kadar olan veri hattındaki serialization ve parse maliyetini sıfıra indirmek amacıyla kurgulandı.

## 2. Problem: JSON Darboğazı ve Main Thread Kilitlenmesi

Geleneksel web mimarilerinde veritabanı sorgu sonucu API katmanında JSON formatına çevrilir ve HTTP üzerinden gönderilir. 250.000 satırlık bir veri seti transfer edildiğinde:
1. **Sunucu Tarafında Yüksek CPU ve GC Baskısı:** C# veya Node.js tarafında yüz binlerce nesne türetilir; string serileştirme sunucu CPU'sunu yakar ve Garbage Collector (GC) duraklamalarına yol açar.
2. **25MB Şişmiş Payload:** JSON'un metin tabanlı anahtar-değer yapısı (`{"timestamp": 1714521000, "temperature": 4.12}`) tekrarlayan string'ler yüzünden ~24.8MB ağ boyutu üretir.
3. **Tarayıcı Arayüzünün Donması (UI Freeze):** Client tarafında `JSON.parse()` çalıştırıldığında tarayıcının single-threaded JavaScript motoru 850 milisaniye boyunca kilitlenir; sayfa donar ve kullanıcı etkileşimi kesilir.

### A. Veritabanından Doğrudan Columnar RecordBatch Üretimi
Backend servisi, veritabanından satır satır nesne oluşturmak yerine PostgreSQL akışını doğrudan ikili columnar **memory buffer**'lara (contiguous memory buffers) doldurur. Değerler satır satır değil; sütun dizileri (Timestamp Array, Float64 Array) halinde organize edilir.

### B. HTTP/2 IPC Streaming
Oluşturulan Apache Arrow `RecordBatch` blokları `application/vnd.apache.arrow.stream` MIME tipiyle **client**'a akıtılır. Veri tüm sorgu bitmeden ilk blok hazır olduğu anda akmaya başlar (chunked streaming).

### C. Zero-Copy Tarayıcı Eşleme
Gelen ikili akış tarayıcıda bir `ArrayBuffer` olarak karşılanır. JavaScript tarafında Apache Arrow kütüphanesi bu buffer'ın üzerine doğrudan bir memory view açar:
- `JSON.parse` veya nesne kopyalama adımı yoktur.
- 250.000 adet `Float64` sıcaklık değeri doğrudan WebGL grafik kütüphanesine veya Canvas render fonksiyonuna bellek adresi olarak verilir.
